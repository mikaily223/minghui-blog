# 第 0 章　数学与神经网络基础

**学习目标**

- 理解向量、点积、矩阵乘法、softmax 四个数学工具,并能手算小例子。
- 理解神经元、层、激活函数,知道"一层"为什么等价于一次矩阵乘法。
- 用自己的话说清模型是如何通过损失、反向传播、梯度下降"学习"的。

整个 Transformer 没有任何高深的数学魔法,它只是把本章这几样基本工具巧妙地组装起来。记住一个贯穿全书的目标:**本章的四个数学工具,恰好就是后面注意力机制公式里的全部零件**。学完本章再看那个公式,你会发现每一块都认识。

## 0.1　向量与点积

**向量**就是一串有序的数字,例如 `[0.2, -1.3, 0.8]`。它有几个分量,就称为几维向量。在 Transformer 中,每一个词(更准确地说是 token)都会被转换成一个向量,这个向量称为**词嵌入(embedding)**。你只需要建立一个直觉:**意思相近的词,它们的向量在空间中也彼此靠近**——"猫"和"狗"的向量,会比"猫"和"汽车"的更接近。

**点积**是两个向量之间一种最基本的运算:把对应位置的数字相乘,再全部加起来。

```
a = [1, 2, 3],  b = [4, 5, 6]
a · b = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

算法很简单,但它的**含义**才是关键:点积衡量两个向量有多"对齐"、多相似。结果是一个大正数,说明两个向量方向相近(相似);接近零,说明它们几乎无关;是负数,说明方向相反。

更精确地说,点积同时混入了两样东西:`a · b = |a| × |b| × cos(夹角)`。其中 `cos(夹角)` 是纯粹的"方向相似度",而点积还乘上了两个向量各自的长度。这意味着一个数值很大的向量,哪怕方向没那么吻合,也可能靠"个头大"刷出较高的点积。

> **为什么重要**:在注意力机制中,"两个词有多相关"这个判断,就是用它们向量的点积算出来的。请把"点积 = 相似度"刻在脑子里。

## 0.2　矩阵乘法

**矩阵**就是把数字排成表格(若干行若干列)。你可以把它看成"一摞向量",也可以看成一种"变换器"——输入一个向量,输出一个新向量。

矩阵乘法的规则依然是点积:用左边矩阵的**每一行**,分别去和右边的**每一列**做点积。

```
A = [1 2]      x = [5]
    [3 4]          [6]

A·x 第一个分量 = 第一行 · x = 1×5 + 2×6 = 17
A·x 第二个分量 = 第二行 · x = 3×5 + 4×6 = 39
结果 = [17, 39]
```

能相乘有一个前提:**左边矩阵的列数,必须等于右边矩阵的行数**。这就是为什么以后你会频繁看到大家讨论"维度对不对得上"。

矩阵乘法的意义极其重大:**神经网络的一层,本质上就是一次矩阵乘法**。而且,你可以把一句话里所有词的向量堆成一个矩阵,用一次矩阵乘法同时处理完它们——这正是后面 Transformer 能够**并行计算**的根源。

## 0.3　Softmax

设想你手上有几个原始分数,比如 `[2, 1, 0]`,有大有小。你希望把它们转换成一组**权重**:全部为正、并且加起来正好等于 1(也就是一个概率分配)。**Softmax** 做的就是这件事。

它分两步:先对每个数做指数运算 `e^x`(保证结果为正,并把差距拉大),再让每个数除以它们的总和。

```
分数 = [2, 1, 0]
取指数:e^2 ≈ 7.39,  e^1 ≈ 2.72,  e^0 = 1
总和 ≈ 7.39 + 2.72 + 1 = 11.11
结果 ≈ [0.665, 0.245, 0.090]   （三者相加 = 1）
```

注意 softmax 会**放大差距**:原本 2 只比 1 大一点,转换后 0.665 却接近 0.245 的三倍。

softmax 在 Transformer 里出现在多个地方:注意力用它把"相关性分数"变成"该分配多少注意力"的权重;掩码用它把某些位置压成 0;模型最后预测下一个词时,也用它给每个候选词打出概率。

## 0.4　神经元与层

一个**神经元**做两步事。第一步:把输入的每个数乘上各自的权重(weight),加起来,再加一个偏置(bias);第二步:把结果送进一个"激活函数"。写成式子就是:

```
输出 = 激活函数( w·x + b )
```

注意 `w·x` 正是点积。它衡量的是"输入 x 和权重 w 有多像"——你可以把权重向量 `w` 想象成这个神经元"专门要找的一个模板",`w·x` 越大,表示输入越符合这个模板,神经元反应越强。所以一个神经元本质上是个**特征探测器**。

那个偏置 `b` 是一个**可学习的门槛**:它把整个加权和上下平移,相当于给神经元设定一条"及格线"——输入要和模板吻合到什么程度,才算真正激活。请注意,`b` 的作用是"设门槛",不是"防止数值太小"。

把很多神经元并排放在一起,就构成一**层**。当你把一层里所有神经元的权重堆在一起,整层做的事正好就是一次矩阵乘法 `W·x + b`。这种最基础的层叫**线性层 / 全连接层**。记住这个名字,后面 Transformer 内部到处都是它。

## 0.5　激活函数

为什么神经元一定要有激活函数这一步?因为如果没有它,把很多线性层叠起来,在数学上仍然等价于**一个**线性层——叠一百层和叠一层没有区别,网络学不到复杂的模式。激活函数引入了"弯曲"(非线性),让网络能够拟合复杂的关系。

最常见的激活函数是 ReLU,规则简单到极致:`ReLU(x) = max(0, x)`,即负数全部归零,正数原样保留。Transformer 中常用它的平滑版本 GELU,但你现在理解 ReLU 的思路就足够了——它们的作用都一样:制造非线性。

## 0.6　模型是怎么"学"的

把若干层串起来:输入 → 线性层 → 激活函数 → 线性层 → …… → 输出。层数越多网络越"深",这就是"深度学习"里"深度"二字的由来。但此刻网络里的权重全是随机的,它什么也不会。它如何学会任务?分三步理解,这三步串成一条线。

**损失函数(Loss)**:给网络喂一个输入,它给出一个预测;我们手上有正确答案;损失函数用来量化"预测离正确答案有多远"。预测越准,损失越小。学习的目标就是把损失降到最低。

**反向传播(Backpropagation)**:网络里可能有上亿个权重,我们怎么知道每个权重该往哪个方向、调多少?反向传播就是高效计算这件事的算法。它从损失出发,利用链式法则一层层往回推,算出每个权重的**梯度**——也就是"该往哪个方向、改多大才能降低损失"。注意:它只产出这个"方向信息",自己并不动手改权重。

**梯度下降(Gradient Descent)**:用一个比喻——你蒙着眼站在山坡上,想走到山谷最低点(损失最小)。你感知脚下哪个方向最陡,朝下坡迈一小步,再感知、再迈一小步,直到谷底。这里"最陡的下坡方向"就是梯度,"迈多大一步"叫学习率。梯度下降拿着反向传播算出的梯度,**真正去更新权重**。

> **口诀**:反向传播管"算账"(算出每个权重该怎么改),梯度下降管"花钱"(照着账单真正去改)。两者配合,网络就在一轮轮训练中慢慢学会任务。实践中这些都由 PyTorch 这类框架自动完成。

## 本章小结

词被表示成**向量**;网络用**线性层(矩阵乘法)**和**激活函数**层层加工向量;**点积**衡量相似、**softmax** 把分数转成权重;整个网络通过**损失 + 反向传播 + 梯度下降**学会任务。这套东西就是后面所有内容的地基。

# 第 1 章　为什么需要 Transformer

**学习目标**

- 理解序列数据为什么特殊,以及 RNN 如何处理它。
- 说清 RNN 的两个致命痛点。
- 理解 LSTM 缓解了什么、没解决什么,从而明白 Transformer 的动机。

本章先不碰 Transformer 本身,而是认识它的前辈 RNN 和 LSTM,体会它们的痛点。理解了痛点,你才会明白 Transformer 那些设计为什么"非这样不可"。

## 1.1　序列数据与顺序的重要性

语言是一种序列数据:词一个接一个出现,而且**顺序至关重要**。"狗咬人"和"人咬狗"用词完全相同,意思却相反。此外,句子长度还不固定。因此处理语言的模型必须做到两件事:既理解每个词,又能把前面读过的内容"记在心里",用来理解后面的词。

## 1.2　RNN:靠一个会更新的"记忆"

RNN 的核心想法很符合直觉,就像你读句子的过程:从左到右一个词一个词地读,脑中始终维护着一份"到目前为止的理解"。每读到一个新词,就用"新词 + 脑中已有的理解"更新出一份新的理解。

这份"脑中的理解"在 RNN 里叫**隐藏状态(hidden state)**,本质是一个向量。它的更新其实就是一个层,同时接收两样输入:当前这个词的向量,和上一步传来的隐藏状态。

```
词₁ → [RNN] → h₁
              ↓（把记忆传给下一步）
词₂ → [RNN] → h₂
              ↓
词₃ → [RNN] → h₃ → ……
```

每一步的 `h` 都浓缩了"从开头到现在"读过的所有信息,再传给下一步。这种"把状态一环扣一环传下去"的结构,就叫**循环(Recurrent)**。这个设计很优雅,但它有两个致命痛点。

## 1.3　两大致命痛点

**痛点一 · 长距离依赖被稀释**。看这句话:"我在**法国**长大,小时候搬过好几次家……所以我能说一口流利的 ____。"要正确填出"法语",模型必须记得开头的"法国"。但在 RNN 里,这条信息要从第一个词经过几十个隐藏状态一环环传到结尾——就像一句话在很多人之间口耳相传,传到最后早就走样或丢失了。距离越远,信息被稀释得越厉害。在训练上,这表现为有名的"梯度消失"问题。

**痛点二 · 无法并行**。注意上面那张图:`h₂` 必须等 `h₁` 算完才能算,`h₃` 又必须等 `h₂`。每一步都依赖上一步,所以只能一个词一个词地排队计算,无法同时进行。这意味着 RNN 用不上现代 GPU"一次算一大批"的能力,句子越长,训练越慢。

## 1.4　LSTM:打了补丁,但没断根

为了缓解"记不住远处信息"的问题,人们改进出了 LSTM。它在 RNN 的基础上加了一条专门的"记忆传送带",以及几个叫**门(gate)**的开关。

门的本质是一组 0 到 1 之间的"阀门"值——0 表示完全关闭、不让信息通过,1 表示完全放行。这些 0 到 1 的值由 **sigmoid** 函数把任意数挤压而来,再用"对应位置相乘"去控制信息通过多少。三个门各管一摊:遗忘门决定抹掉哪些旧记忆,输入门决定写入多少新信息,输出门决定这一步对外输出什么。

> **关键**:门"该记什么、忘什么"不是人手写死的规则,而是在训练中通过梯度下降**学出来**的。

但请记住:LSTM 只**缓解了痛点一(长距离)**,对**痛点二(并行)无能为力**——它骨子里仍是"一个词一个词顺序处理"的循环结构。

## 1.5　Transformer 的破局思路

到这里你已能看出问题的核心:麻烦全都来自"循环"——信息非得沿着一条长链一环环传递。Transformer 做了一个大胆的决定:**干脆把循环彻底扔掉**。它让句子里的每个词,都能"一步直达"地去看其他所有词,并自己判断该重点关注谁。

这一招同时干掉了两个痛点:第一个词和第一百个词可以**直接**建立联系,不再被中间环节稀释(解决长距离);而"所有词同时互相查看"的操作本质是几次大矩阵乘法,**天然可以并行**(解决速度)。实现这个想法的机制,就叫**注意力(Attention)**,也是下一章的主角。

## 本章小结

RNN 用隐藏状态顺序处理序列,但受困于长距离稀释与无法并行;LSTM 用门控缓解了前者,却没解决后者。Transformer 抛弃循环、改用注意力,一举解决两个痛点。

3. LSTM 解决了两个痛点中的哪一个?另一个呢?

# 第 2 章　注意力机制(核心)

**学习目标**

- 用一句话说清注意力在做什么。
- 理解 Query / Key / Value 三个角色及其分工。
- 完整走通自注意力的计算流程,并看懂那个著名公式。

这是整个 Transformer 的心脏。好消息是:第 0 章学的点积、softmax、矩阵乘法,在这一章会全部汇合。

## 2.1　核心直觉:基于相关性的加权求和

看这句话:"那只动物没能过马路,因为**它**太累了。"这里的"它"指什么?是"动物"。可"它"这个字本身没什么信息,模型要搞清楚它指谁,就必须回头看别的词,而且要**重点关注"动物"、不太理会"马路"**。

注意力机制做的就是这件事:**给每个词生成一个新的表示,这个新表示是"句子里所有词的信息"的加权求和,而权重的大小,取决于每个词跟它有多相关**。

拆出来就是两个动作:先算"该关注谁多少"(相关性权重),再"按权重把大家的信息汇总起来"(加权求和)。这两步你都会:相关性用**点积**算,权重用 **softmax** 归一化,最后做**加权求和**。整个注意力,就是这三样东西的组合。

## 2.2　Query、Key、Value

为了把上面的想法做精细,Transformer 给每个词配了三个角色,用一次"检索"来理解最为贴切:

- **Query(查询)**:我现在想找什么。——相当于你心里的搜索词。
- **Key(键)**:每个词对外挂出的"标签",用来和别人的查询做匹配。——相当于每本书的索引标签。
- **Value(值)**:这个词真正携带、准备贡献出去的信息内容。——相当于书里的实际内容。

流程是:拿你的 Query 去和每个词的 Key 做匹配(点积,看有多吻合)→ 把匹配分数转成权重(softmax)→ 按权重去汇总各词的 Value。谁的 Key 和你的 Query 最对得上,谁的 Value 就在结果里占最大份额。

这三个向量从哪来?每个词用自己的词向量,分别乘上三个**待学习的权重矩阵 W_Q、W_K、W_V**,就生成出它自己的 Query、Key、Value。还记得吗——乘一个权重矩阵,就是过一个线性层。因为查询、键、值全都来自同一句话里的这些词、它们互相之间做注意力,所以这套机制叫**自注意力(Self-Attention)**。

> **务必分清**:做相似度匹配用的是 **Key**;被加权求和、真正流进新表示的是 **Value**。Key 和 Value 拆成两个独立向量,是因为"一个词凭什么值得被关注"和"它能提供什么有用信息"不一定相同。比如某个词的标签(Key)是"数学",但你真正想从它那里取走的内容(Value)可能是"代数"。

## 2.3　自注意力完整流程

以"它"这个词为例,看它如何通过注意力搞清自己指代谁:

1. "它"拿出自己的 Query 向量 q。
2. 句子里每个词(包括"它"自己)都亮出自己的 Key 向量。
3. 用 q 和每个词的 Key 做**点积**,得到一串相关性分数。"它"的 Query 和"动物"的 Key 会得到很高的分。
4. 把这些分数**除以 √d 缩放**(d 是向量维度)。这是因为点积会随维度变大而变得过大,缩放能把分数压在合理范围,避免 softmax 后过于极端。
5. 把缩放后的分数过 **softmax**,得到一组加起来为 1 的权重,例如:动物 0.7,马路 0.1,它自己 0.2。
6. 按这组权重,对各个词的 **Value 向量做加权求和**,得到"它"的新表示。

> **注意**:权重是**混合比例**(像混音台上每条音轨的音量推杆),不是"可信度";而且最终结果是**所有 Value 的加权混合**,不是"赢家通吃"只取最高的那一个。

一个具体的加权求和例子:

```
权重:   动物 0.7,  马路 0.1,  它 0.2
Value:  动物[2,0], 马路[0,4], 它[1,1]

新表示 = 0.7×[2,0] + 0.1×[0,4] + 0.2×[1,1]
       = [1.4,0] + [0,0.4] + [0.2,0.2]
       = [1.6, 0.6]
```

因为"动物"权重最大,"它"的新表示主要由"动物"的信息主导——"它"成功地把"动物"的含义吸收了进来。这就是注意力的全部魔法。

## 2.4　公式

把上面对所有词同时进行的操作写成一个式子,就是大名鼎鼎的:

```
Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V
```

逐块对照你刚做的事:Q、K、V 是把所有词的查询、键、值各自堆成的矩阵(一行一个词);`Q·Kᵀ` 一次性算出所有词两两之间的点积分数;`/√d` 是缩放;`softmax` 把每行分数变成权重;最后乘上 `V`,就是对 Value 做加权求和。**唯一的区别是:它用矩阵乘法,把全句所有词的这套流程一次并行算完了。**

## 2.5　回收两大痛点

回头看第 1 章 RNN 的两大痛点,注意力一招同时解决:第一个词的 Query 可以**直接**和第一百个词的 Key 做点积,不必经过中间环节的稀释(长距离);整个过程就是几次大矩阵乘法,全句所有词**同时处理**(并行)。

## 本章小结

注意力 = 用点积算相关性 → 用 softmax 转权重 → 对 Value 做加权求和。Query 提问、Key 匹配、Value 提供内容;÷√d 防止分数过大。它天然解决了长距离与并行两个问题。

# 第 3 章　完整的 Transformer 模块

**学习目标**

- 理解多头注意力解决了单头的什么局限。
- 理解位置编码补救了注意力的什么缺陷。
- 理解前馈网络、残差连接、层归一化各自的作用,并能拼出一个完整模块。

本章在注意力之上加装几个关键零件,拼出一个完整的 Transformer 模块。

## 3.1　多头注意力

你现在掌握的注意力,每个词只能按**一种**"相关性"去汇总信息。但词与词的关系是多种多样、同时存在的:"它"既要搞清楚指代哪个名词(语义),又可能想知道自己是哪个动词的主语(语法),还可能关心前后挨着哪些词(邻近)。单独一套 Q/K/V 只能算出一种注意力模式,顾此失彼。

解决办法很直接:**同时跑好几套独立的注意力,每套都有自己的 W_Q、W_K、W_V**,每一套叫一个"头(head)"。因为权重矩阵各自独立、各自训练,每个头会自发地学会专注于一种不同的关系。最后把所有头的结果拼接起来,再过一个线性层融合成一个输出。

> **两个易错点**:其一,头的数量是设计选项,常见 8、12 乃至上百个,并不固定;其二,各个头"专攻哪种关系"是它们在**训练中自己分化**出来的,**不是人指派**的,而且"一头一职"只是帮助理解的粗略图景。

补一个实用细节:若总维度是 d、有 h 个头,通常每个头只在 d/h 的小维度里工作,所以总计算量与单头时相当,等于把同样的预算拆成几份各看一个角度。

## 3.2　位置编码

这里有个特别精妙的洞察:**注意力机制本身,其实根本不知道顺序**。回想它的计算——一堆基于点积的加权求和。如果你把句子里词的顺序打乱,那些两两点积和加权求和的结果完全不变。也就是说,在注意力眼里,一句话只是"一袋子词",而不是"一串有先后的词"。这正是它能高度并行的代价。

但"狗咬人"与"人咬狗"意思相反,顺序绝不能丢。怎么补回来?办法很巧:在把词向量送进注意力之前,**给每个位置额外加上一个"位置向量"**。第 1 个位置加一种向量,第 2 个位置加另一种……这样送进去的就不再是单纯的"词义",而是"词义 + 它在第几位"。注意力虽然分不清顺序,但既然位置信息已掺进输入,它就能学着利用了。

那个位置向量,原始论文用一套固定的**正弦/余弦波**(不同频率)给每个位置生成独一无二的"指纹";后来也有可学习式、相对位置(如 RoPE)等变体,但目的都一样——把顺序信息注入进去。

## 3.3　前馈网络(FFN)

注意力擅长在词与词之间**搬运、混合**信息,但它本质是加权求和,没怎么对信息做深加工。于是在注意力之后,接一个前馈网络:**把每个词的向量,单独送进一个小网络里处理一遍**(同一个网络分别作用在每个词上)。这个网络就是第 0 章学的东西——两个线性层中间夹一个激活函数,通常先升到 4 倍维度,再压回原维度。

所以一个模块里的分工很清晰:**注意力负责"收集"(从别的词那里取相关信息),前馈网络负责"加工"(让每个词独自把信息再思考一遍)**。

## 3.4　残差连接

Transformer 要把很多模块叠得很深(几十甚至上百层),但信息和梯度在层层传递中会衰减,网络一深就难训。解法巧妙得令人发指:本来一层做的是 `输出 = 某层(输入)`,现在改成:

```
输出 = 输入 + 某层(输入)
```

也就是把这层的原始输入,直接加回到它的输出上。这相当于修了一条绕过该层的"高速旁路":信息可以直接穿过,梯度回传也有一条近路;而且每一层不必从零重建一切,只需学习"该在输入上做的微调"。正是这条旁路,让网络能放心地往深里叠。

单看一处残差,加回来的是**该子层自己的输入**(上一步的结果);但因为层层都这么做,主干会不断累加——展开后约等于"最初的词向量 + 沿途每层各自的贡献之和"。这条贯穿始终的主干,业内称为"残差流"。

## 3.5　层归一化

数据流过很多层之后,里面的数值可能越漂越大或越缩越小,导致训练不稳定。层归一化在关键位置把每个词的向量**重新缩放到标准范围**(大致均值 0、方差 1),再用可学习的参数微调。打个比方,它就像在音响每一级之间装个自动音量平衡器,保证信号既不爆音也不至于消失,始终待在健康稳定的区间,让训练又稳又快。

## 3.6　拼装一个完整模块

把"多头自注意力"和"前馈网络"两个子层,各自用"残差 + 层归一化"包起来,串在一起:

```
       输入向量（已加位置编码）
              │
        ┌─────┴─────┐
        │  多头自注意力 │
        └─────┬─────┘
         (相加：残差)
              │
          层归一化
              │
        ┌─────┴─────┐
        │  前馈网络 FFN │
        └─────┬─────┘
         (相加：残差)
              │
          层归一化
              │
              ▼
        输出（交给下一个模块）
```

然后把这样一个模块**原样堆叠 N 份**(比如 6、12、96 层),前一个模块的输出喂给后一个。每经过一层,每个词的表示就被进一步精炼。这一整摞模块,就构成了 Transformer 的**编码器(Encoder)**。

## 本章小结

多头让模型从多个角度看关系(分工由训练自学);位置编码补回注意力丢失的顺序;前馈网络让每词独自加工;残差让网络可叠深;层归一化稳住数值。它们与注意力一起,组成可堆叠的 Transformer 模块。

2. 为什么说注意力"本身不知道顺序"?如何补救?
3. 一个模块里,注意力子层和前馈子层各自的职责是什么?
4. 残差连接 `输出 = 输入 + 层(输入)` 为什么能让网络叠得很深?

# 第 4 章　编码器-解码器、掩码与文本生成

**学习目标**

- 说清编码器与解码器的根本区别。
- 理解解码器的三个子层,尤其是交叉注意力。
- 理解因果掩码,以及训练与推理两种工作方式的区别。

第 3 章你搭好的其实是 Transformer 的"编码器"。本章补全另一半,并搞清它到底如何生成文字。

## 4.1　编码器与解码器的根本区别

先抛开术语。**编码(encode)= 把文字变成"含义"**:读入一段文字,把它压缩成富含语义的内部表示(一堆向量),即"读懂"。**解码(decode)= 把"含义"变回文字**:拿着内部理解,一个词一个词地写出来,即"表达"。

想象一个人类翻译员翻译 "I love cats":他先**通读整句英文、在脑中形成完整理解**(编码:文字→含义),再**根据理解把中文一个字一个字写出来**(解码:含义→文字)。

| | 编码器 Encoder | 解码器 Decoder |
|---|---|---|
| 任务 | 读懂输入 | 生成输出 |
| 产出 | 向量(理解) | 文字(一个个词) |
| 看的范围 | 整句双向(无掩码) | 只看已生成的(因果掩码) |
| 工作方式 | 一次性处理整句 | 一个词一个词循环生成 |

它俩分成两个模块,是因为"读懂源句"和"写出目标句"是两种不同的活儿:读懂时希望纵览全句,生成时却只能依赖已写出的部分。

## 4.2　解码器的三个子层

解码器模块长得像编码器模块,但有**三个**子层:

1. **带掩码的自注意力**:解码器对"已经生成的目标词"做自注意力,但加了一道掩码,只能看到自己和前面的词,看不到未来(详见 4.3)。Q、K、V 都来自目标侧。
2. **交叉注意力**:这是 Q/K/V 设计的精彩回报——**Query 来自解码器**(我现在想生成什么?),而 **Key 和 Value 来自编码器的输出**(源句)。于是解码器用自己的 Query 去"查询"源句,把相关信息拉过来。这正是源语言与目标语言挂上钩的地方。
3. **前馈网络**:和之前一样。

三个子层同样各自包"残差 + 层归一化"。

> **交叉注意力的作用**:提问的是解码器(所以 Q 来自它),被查的是源句(所以 K/V 来自编码器)。这个不对称就是重点。没有这一层,解码器根本不知道自己在翻译什么。

## 4.3　因果掩码:为什么 + 怎么做

**为什么**:生成时是一个词一个词往外蹦的,当模型要生成第 5 个词时,第 6、7 个词还不存在。如果训练时允许第 5 个位置偷看到第 6 个位置(也就是正确答案),模型就会"作弊",什么也学不到。所以必须禁止每个位置看到它后面的位置。

**怎么做**:在 softmax 之前,把指向"未来位置"的注意力分数全部设成负无穷(−∞)。因为 e^(−∞) = 0,这些未来位置经 softmax 后权重变成**恰好为 0**,等于完全屏蔽——不是"几乎看不见",而是一点都不漏。这道遮罩叫"因果掩码",它只加在解码器的带掩码自注意力这一层。

## 4.4　训练与推理:两种工作方式

**训练时(teacher forcing)**:正确的目标句我们手上已经有了(它就是训练数据)。于是把整句目标句**一次性**全喂进解码器,靠因果掩码保证每个位置只能用它前面的词去预测下一个词。因为全句**并行**处理,训练很快。

**推理时(自回归)**:此时没有答案,只能一个词一个词地生成。流程是:给一个特殊的"开始符"→ 解码器吐出第 1 个词 → 把它接回去 → 吐出第 2 个词 → ……直到吐出"结束符"。这个过程天生是**串行**的,所以生成比训练慢。

> **关键**:因果掩码让"训练时能并行"和"生成时只能看过去"这两件看似矛盾的事同时成立。

## 4.5　输出层:如何选出一个词

解码器最后一层输出的每个向量,会过一个线性层,映射成一个**和词表一样长**的向量,再过 softmax,得到"下一个词是词表里每个词的概率"。取概率最高的(或按概率采样),就是生成的那个词。

## 本章小结

编码器读懂(双向),解码器生成(因果掩码、自回归);解码器用交叉注意力(Q 来自解码器、K/V 来自编码器)连接源与目标;因果掩码用 −∞ 屏蔽未来,使训练并行而生成只看过去。

2. 交叉注意力中,Q、K、V 分别来自哪里?它的作用是什么?
3. 因果掩码具体如何用 softmax 实现"看不到未来"?

# 第 5 章　三大变体:BERT / GPT / T5

**学习目标**

- 理解为什么不一定两半都要,从而分化出三个家族。
- 了解 BERT、GPT、T5 各自的结构、训练方式与擅长任务。
- 理解"训练目标决定了能不能双向"这一要点。

学完本章,你就能把前面所有知识和日常使用的大模型连起来。

## 5.1　核心领悟:不一定两半都要

你已经知道编码器负责"读懂"、解码器负责"生成"。人们很快发现:很多任务其实只用得上其中一半。于是分化出三个家族。

## 5.2　只要编码器:BERT(理解专家)

只保留一摞编码器模块。因为不需要逐词生成,它**不加掩码**,每个词能同时看到左右两边的全部上下文——这叫**双向**。

它怎么训练?用"完形填空":随机遮住输入里的一些词,让模型用**左右两边的上下文**一起把被遮的词猜出来。正因为是填空、不是从左往右生成,它才能放心地双向看。

它产出"理解向量",不直接吐文字,使用模式是 **BERT(读懂)+ 一个小任务层(做决策)**。常见应用:

- **文本分类**:情感分析(好评/差评)、内容审核、客服意图路由。
- **命名实体识别(NER)**:抠出人名、机构、时间;简历、合同、病历的信息抽取。
- **语义检索 / 嵌入(embedding)**:把文本压成一个"含义向量",意思相近的向量也相近——撑起搜索、推荐,以及 **RAG 的检索环节**(常用 Sentence-BERT 等专门微调的编码器型模型)。
- **抽取式问答**:在给定材料里圈出答案所在的那段文字。
- **句子对关系**:判断两句是否矛盾/重复、给搜索结果排序。

> **为什么如今仍用 BERT**:它小、快、便宜,且输出结构化(一个标签或向量,可直接进流水线),适合海量、低成本地跑(给十亿条评论分类、给全库文档建索引)。它是搜索、推荐、内容审核以及 RAG 检索背后的幕后主力。

## 5.3　只要解码器:GPT / Claude(生成专家,当今主流)

只保留一摞解码器模块,而且因为没有编码器可看,**砍掉了交叉注意力**,每块只剩"带掩码自注意力 + 前馈网络",只保留因果掩码(单向)。

它怎么训练?极其简单:**预测下一个词**——给定前面所有词,猜下一个词是什么,在海量文本上反复练。因为它从小就在练"接着往下写",所以天生擅长生成:续写、对话、写代码、推理。

为什么这一支成了绝对主流?因为"预测下一个词"这件看似简单的事威力惊人——要把下一个词预测准,模型不得不顺带学会语法、事实、逻辑;而且结构简单、容易把规模做大。GPT、Claude、Llama 都属于这一支。大模型变得太强,以至于理解、翻译、摘要等任务也能靠提示词让它生成答案顺手解决,于是 decoder-only 成了通用首选。

## 5.4　两个都要:原始 Transformer / T5(转换专家)

编码器 + 解码器,中间用交叉注意力连接。适合"把一段文字转换成另一段文字"的任务:翻译、摘要。编码器读懂输入,解码器一边生成一边回头查输入。

## 5.5　三者对比

| 家族 | 用哪半 | 看的方向 | 训练方式 | 擅长 | 代表 |
|---|---|---|---|---|---|
| 只要编码器 | 编码器 | 双向(无掩码) | 完形填空(遮词预测) | 理解、分类、检索 | BERT |
| 只要解码器 | 解码器(无交叉注意力) | 单向(因果掩码) | 预测下一个词 | 生成、对话、写作 | GPT、Claude |
| 都要 | 编码器 + 解码器 | 编码双向 / 解码单向 | 输入 → 输出 | 翻译、摘要 | 原始 Transformer、T5 |

## 5.6　一个值得记住的"啊哈":训练目标决定方向

为什么 BERT 能双向、GPT 只能单向?根子在训练方式:BERT 做完形填空,要猜中间的空,当然要用两边的信息,所以可以双向;GPT 练的是"预测下一个词",如果让它看到后面的词,就等于偷看答案,所以只能看过去。**看的方向,是被训练目标逼出来的。**

## 本章小结

按任务只取需要的部分:只要理解 → 编码器型(BERT);只要生成 → 解码器型(GPT/Claude);要做"输入转输出" → 编码器-解码器型(T5)。训练目标决定了模型是双向还是单向。

# 附录 A　易错点汇总

1. **偏置 b** 是可学习的门槛/偏移,决定"像到什么程度才激活",不是"防止数值太小"。
2. 注意力中被加权求和、传入新表示的是各词的 **Value**;Key 只用于匹配。
3. 注意力权重是各 Value 的**混合比例**,且是**所有 Value 的加权混合**,不是"赢家通吃"。
4. 解决 RNN 两痛点的是**注意力本身**(直连 + 并行);**位置编码不解决这两个痛点**,它补救的是注意力的"顺序失明"。
5. 多头各头的分工是**训练自分化**的,**非人指派**;头数也不固定。
6. 两个子层别说反:**注意力 = 收集,前馈 = 加工**。
7. 残差:单处加回的是"该子层的输入";"最初输入 + 各层贡献"是整摞层层累加后的效果。
8. **交叉注意力**:Q 来自解码器,K/V 来自编码器输出,别记反。
9. **因果掩码**:未来位置设 −∞,softmax 后权重**恰好为 0**(完全屏蔽);只加在解码器的带掩码自注意力。
10. 编码器(读懂、双向、无掩码)与解码器(生成、单向、有掩码)职责不同,别混。
11. **双向还是单向,由训练目标决定**:填空可双向(BERT),预测下一词只能单向(GPT)。
12. decoder-only 没有交叉注意力,因为没有编码器可看。
