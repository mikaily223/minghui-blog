# 第 0 章　数学与神经网络基础

**学习目标**

- 理解向量、点积、矩阵乘法、softmax 四个数学工具,并能手算小例子。
- 理解神经元、层、激活函数,知道"一层"为什么等价于一次矩阵乘法。
- 用自己的话说清模型是如何通过损失、反向传播、梯度下降"学习"的。

整个 Transformer 没有任何高深的数学魔法,它只是把本章这几样基本工具巧妙地组装起来。记住一个贯穿全书的目标:**本章的四个数学工具,恰好就是后面注意力机制公式里的全部零件**。学完本章再看那个公式,你会发现每一块都认识。

## 0.1　向量与点积

**向量**就是一串有序的数字,例如 `[0.2, -1.3, 0.8]`。它有几个分量,就称为几维向量。在 Transformer 中,每一个词(更准确地说是 token)都会被转换成一个向量,这个向量称为**词嵌入(embedding)**。你只需要建立一个直觉:**意思相近的词,它们的向量在空间中也彼此靠近**——"猫"和"狗"的向量,会比"猫"和"汽车"的更接近。

**点积**是两个向量之间一种最基本的运算:把对应位置的数字相乘,再全部加起来。

```
a = [1, 2, 3],  b = [4, 5, 6]
a · b = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

算法很简单,但它的**含义**才是关键:点积衡量两个向量有多"对齐"、多相似。结果是一个大正数,说明两个向量方向相近(相似);接近零,说明它们几乎无关;是负数,说明方向相反。

更精确地说,点积同时混入了两样东西:`a · b = |a| × |b| × cos(夹角)`。其中 `cos(夹角)` 是纯粹的"方向相似度",而点积还乘上了两个向量各自的长度。这意味着一个数值很大的向量,哪怕方向没那么吻合,也可能靠"个头大"刷出较高的点积。

> **为什么重要**:在注意力机制中,"两个词有多相关"这个判断,就是用它们向量的点积算出来的。请把"点积 = 相似度"刻在脑子里。

## 0.2　矩阵乘法

**矩阵**就是把数字排成表格(若干行若干列)。你可以把它看成"一摞向量",也可以看成一种"变换器"——输入一个向量,输出一个新向量。

矩阵乘法的规则依然是点积:用左边矩阵的**每一行**,分别去和右边的**每一列**做点积。

```
A = [1 2]      x = [5]
    [3 4]          [6]

A·x 第一个分量 = 第一行 · x = 1×5 + 2×6 = 17
A·x 第二个分量 = 第二行 · x = 3×5 + 4×6 = 39
结果 = [17, 39]
```

能相乘有一个前提:**左边矩阵的列数,必须等于右边矩阵的行数**。这就是为什么以后你会频繁看到大家讨论"维度对不对得上"。

矩阵乘法的意义极其重大:**神经网络的一层,本质上就是一次矩阵乘法**。而且,你可以把一句话里所有词的向量堆成一个矩阵,用一次矩阵乘法同时处理完它们——这正是后面 Transformer 能够**并行计算**的根源。

## 0.3　Softmax

设想你手上有几个原始分数,比如 `[2, 1, 0]`,有大有小。你希望把它们转换成一组**权重**:全部为正、并且加起来正好等于 1(也就是一个概率分配)。**Softmax** 做的就是这件事。

它分两步:先对每个数做指数运算 `e^x`(保证结果为正,并把差距拉大),再让每个数除以它们的总和。

```
分数 = [2, 1, 0]
取指数:e^2 ≈ 7.39,  e^1 ≈ 2.72,  e^0 = 1
总和 ≈ 7.39 + 2.72 + 1 = 11.11
结果 ≈ [0.665, 0.245, 0.090]   （三者相加 = 1）
```

注意 softmax 会**放大差距**:原本 2 只比 1 大一点,转换后 0.665 却接近 0.245 的三倍。

softmax 在 Transformer 里出现在多个地方:注意力用它把"相关性分数"变成"该分配多少注意力"的权重;掩码用它把某些位置压成 0;模型最后预测下一个词时,也用它给每个候选词打出概率。

## 0.4　神经元与层

一个**神经元**做两步事。第一步:把输入的每个数乘上各自的权重(weight),加起来,再加一个偏置(bias);第二步:把结果送进一个"激活函数"。写成式子就是:

```
输出 = 激活函数( w·x + b )
```

注意 `w·x` 正是点积。它衡量的是"输入 x 和权重 w 有多像"——你可以把权重向量 `w` 想象成这个神经元"专门要找的一个模板",`w·x` 越大,表示输入越符合这个模板,神经元反应越强。所以一个神经元本质上是个**特征探测器**。

那个偏置 `b` 是一个**可学习的门槛**:它把整个加权和上下平移,相当于给神经元设定一条"及格线"——输入要和模板吻合到什么程度,才算真正激活。请注意,`b` 的作用是"设门槛",不是"防止数值太小"。

把很多神经元并排放在一起,就构成一**层**。当你把一层里所有神经元的权重堆在一起,整层做的事正好就是一次矩阵乘法 `W·x + b`。这种最基础的层叫**线性层 / 全连接层**。记住这个名字,后面 Transformer 内部到处都是它。

## 0.5　激活函数

为什么神经元一定要有激活函数这一步?因为如果没有它,把很多线性层叠起来,在数学上仍然等价于**一个**线性层——叠一百层和叠一层没有区别,网络学不到复杂的模式。激活函数引入了"弯曲"(非线性),让网络能够拟合复杂的关系。

最常见的激活函数是 ReLU,规则简单到极致:`ReLU(x) = max(0, x)`,即负数全部归零,正数原样保留。Transformer 中常用它的平滑版本 GELU,但你现在理解 ReLU 的思路就足够了——它们的作用都一样:制造非线性。

## 0.6　模型是怎么"学"的

把若干层串起来:输入 → 线性层 → 激活函数 → 线性层 → …… → 输出。层数越多网络越"深",这就是"深度学习"里"深度"二字的由来。但此刻网络里的权重全是随机的,它什么也不会。它如何学会任务?分三步理解,这三步串成一条线。

**损失函数(Loss)**:给网络喂一个输入,它给出一个预测;我们手上有正确答案;损失函数用来量化"预测离正确答案有多远"。预测越准,损失越小。学习的目标就是把损失降到最低。

**反向传播(Backpropagation)**:网络里可能有上亿个权重,我们怎么知道每个权重该往哪个方向、调多少?反向传播就是高效计算这件事的算法。它从损失出发,利用链式法则一层层往回推,算出每个权重的**梯度**——也就是"该往哪个方向、改多大才能降低损失"。注意:它只产出这个"方向信息",自己并不动手改权重。

**梯度下降(Gradient Descent)**:用一个比喻——你蒙着眼站在山坡上,想走到山谷最低点(损失最小)。你感知脚下哪个方向最陡,朝下坡迈一小步,再感知、再迈一小步,直到谷底。这里"最陡的下坡方向"就是梯度,"迈多大一步"叫学习率。梯度下降拿着反向传播算出的梯度,**真正去更新权重**。

> **口诀**:反向传播管"算账"(算出每个权重该怎么改),梯度下降管"花钱"(照着账单真正去改)。两者配合,网络就在一轮轮训练中慢慢学会任务。实践中这些都由 PyTorch 这类框架自动完成。

## 本章小结

词被表示成**向量**;网络用**线性层(矩阵乘法)**和**激活函数**层层加工向量;**点积**衡量相似、**softmax** 把分数转成权重;整个网络通过**损失 + 反向传播 + 梯度下降**学会任务。这套东西就是后面所有内容的地基。
